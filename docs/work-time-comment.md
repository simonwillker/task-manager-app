# 作業時間のコメント記録 仕様

Issue #20「作業開始終了時間を記載機能を追加」の仕様書です（実装前の仕様）。

## 目的

タスクの「開始」「終了」ボタンで記録した作業時間を、タスクの**コメント内容**項目に自動で書き込み、編集ダイアログで確認できるようにする。

## 前提（現状）

- タスクには `sessions`（`startedAt` / `endedAt` の配列）があり、「開始」「終了」ボタンで追加・確定される（`PATCH /api/tasks/:id` の `timer: "start" | "end"`）。
- 編集ダイアログ（`#edit-dialog`）には現在、内容と期日の項目のみがある。

## 仕様

### 1. コメント内容項目の追加

- タスクに `comment`（文字列、初期値は空文字）を追加する。
- 編集ダイアログに「コメント内容」欄（複数行テキスト）を追加し、編集ボタンから確認できる。
- 手入力での編集も可能（自動記載は既存の内容の末尾に行を足す）。

### 2. 終了ボタン押下時の自動記載

「終了」を押して作業区間が確定するたびに、**その回の作業時間**を 1 行としてコメントの末尾に追加する。複数回の場合は改行で積み上げる。

| 操作 | コメント内容の結果 |
| --- | --- |
| 1 回目: 開始 → 終了（1 時間 30 分） | `1回目: 01:30:00` |
| 2 回目: 開始 → 終了（45 分） | `1回目: 01:30:00` と改行して `2回目: 00:45:00` |

- 作業時間 = 終了時刻 − 開始時刻（`HH:MM:SS`、時は 24 以上も可）。
- 「n 回目」は確定済みの作業区間の通し番号。
- 要望の「合計時間」は、各回の作業時間を回ごとに 1 行で示すことで表す。全回の総合計が必要な場合は、最終行に `合計: HH:MM:SS` を足す案もある（ユーザー判断事項）。
- 開始ボタンではコメントを変更しない。

### 3. 両バージョンでの動作

- サーバー版: `PATCH` の `timer: "end"` 処理内で、サーバーが記録した時刻から計算して `tasks.comment` に追記する（DB マイグレーションで `comment TEXT NOT NULL DEFAULT ''` を追加）。`PATCH` は `comment` の直接更新も受け付ける。
- 静的版（`localBackend.js`）: 同じ計算・書式で localStorage のタスクの `comment` に追記する。古いデータは `comment` が無ければ空文字として読み込む。
- 両版で書式・行の順序・挙動は同一にする。

### 4. エッジケース

- 開始前の終了、開始中の再度開始は、現行どおり `409`。
- 作業時間が 1 秒未満でも 1 行として記録する（`00:00:00`）。
- コメントが空でない場合は改行を挟んで追記する。空なら先頭行として書く。
