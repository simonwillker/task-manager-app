# 作業時間のコメント記録

Issue #20。「終了」ボタンを押すたびに、作業時間をタスクのコメントへ記録する。サーバー版・静的版で同じ動作。

## 仕様

- タスクに `comment`（文字列、最大 2000 文字、初期値は空）を追加する。
- 「終了」を押すと、その回の作業時間（終了 − 開始）を `N回目: HH:MM:SS` の行として末尾に追記する。N は終了済みの回数。
- 続けて最終行に、終了済み全回の合計を `合計: HH:MM:SS` として書く。次の終了時は古い `合計:` 行を取り除き、新しい回の行と新しい合計行を付け直す。

```
1回目: 01:30:00
2回目: 00:45:00
合計: 02:15:00
```

- コメントは「編集」ボタンの画面で確認でき、手で直して保存できる。手で直した内容は次の追記でも残る。
- 既存のタスク（コメントなし）は空のコメントとして扱う。サーバー版はマイグレーション 6 で `tasks.comment` を追加する。

## 実装箇所

| 場所 | 内容 |
| --- | --- |
| `server/db.js` | マイグレーション 6（`comment` 列） |
| `server/app.js` | `appendWorkTime`、`PATCH /api/tasks/:id` の `comment`、終了時の追記 |
| `public/localBackend.js` | 同じ処理（localStorage 版） |
| `public/index.html` / `public/script.js` | 編集画面のコメント欄 |
| `tests/` | 2回終了したときのコメント内容のテスト（両版） |
